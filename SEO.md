# SEO и индексация pandatv.online

Все файлы ниже лежат в `PandaTV/` — это корень сайта. **Важно:** они работают
только если `PandaTV/` действительно является document root и файлы доступны как
`https://pandatv.online/robots.txt`, а не `.../PandaTV/robots.txt`. Если хостинг
отдаёт сайт из другой папки — перенесите файлы туда, иначе поисковики их не
увидят.

## Что добавлено

| Файл | Зачем |
|---|---|
| `robots.txt` | Правила обхода, ссылка на sitemap, явное разрешение для AI-краулеров (GPTBot, ClaudeBot, PerplexityBot, Google-Extended и др.), блок агрессивных SEO-скраперов (Ahrefs, Semrush, MJ12, DotBot, PetalBot) |
| `sitemap.xml` | Карта сайта с `lastmod` и image-расширением (ключевые изображения для Google Images) |
| `llms.txt` | Краткая выжимка о сервисе для LLM и AI-поиска — формат [llmstxt.org](https://llmstxt.org): описание, тарифы, контакты |
| `llms-full.txt` | Полный текст всех секций сайта, включая все 15 вопросов FAQ — чтобы ChatGPT, Claude и Perplexity отвечали про Panda TV точно, а не придумывали |
| `site.webmanifest` | PWA-манифест: имя, иконки, тема — сайт можно «установить» на телефон |
| `humans.txt` | Информация о команде и стеке |
| `.well-known/security.txt` | Контакт для сообщений об уязвимостях (RFC 9116) |
| `images/icons/icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | Иконки для манифеста и iOS, сгенерированы из логотипа |
| `images/og-cover.jpg` | Превью 1200×630 для ссылок в Telegram, WhatsApp, Facebook, X |

## Что исправлено в `index.html`

- **`<title>` и `description`** — были `Panda TV` и пустой атрибут. Теперь
  осмысленные, с ключевыми словами (IPTV, TorrServe, HD/4K, 40+ стран).
- **`rel=canonical`** — защита от дублей с `www`, `?utm_...`, `index.html`.
- **Open Graph и Twitter Card** — раньше ссылка на сайт в мессенджерах
  выглядела голой, теперь с обложкой, заголовком и описанием.
- **`meta robots`** с `max-image-preview:large` — крупные превью в выдаче.
- **Structured data (JSON-LD):**
  - `Organization` + `ContactPoint` — название, логотип, соцсети, поддержка 24/7;
  - `WebSite`, `WebPage`;
  - `Service` с тремя `Offer` (€6 / €11 / €16) — цены могут попасть в сниппет;
  - `FAQPage` со всеми 15 вопросами — шанс на расширенный FAQ-сниппет.
- **Один `<h1>` вместо шести.** Заголовки секций были `<h1 class="display-1">`;
  шесть H1 на странице размывают тему. Стали `<h2>`, вид не изменился —
  класс `display-1` остался.
- **Невалидная разметка FAQ.** Блок `<details>` лежал внутри `<p class="lead">`,
  браузер закрывал `<p>` раньше времени, и лишний `</section>` закрывал секцию
  `#download` до футера. Исправлено — страница теперь проходит проверку
  вложенности тегов.
- **Незакрытый `</html>`** — добавлен.
- **`alt` у изображений** — были `Author image`, `App Screenshots`, у hero-картинки
  не было вовсе. Теперь описательные.
- **`loading="lazy"` / `decoding="async"`** на картинках ниже первого экрана,
  `fetchpriority="high"` на hero — плюс к Core Web Vitals.
- **`styles.html`** (служебная страница шаблона) закрыта от индексации через
  `noindex`.
- **Шрифты перенесены к себе.** `css/base.css` грузил Nunito Sans и Chivo
  через `@import` с `fonts.googleapis.com`: минус внешний DNS + TLS на
  критическом пути рендера и передача IP посетителя в Google. Теперь файлы
  лежат в `css/fonts/` (подмножества latin и latin-ext, 20 файлов), правила —
  в `css/fonts.css`, подключается через `<link>` перед `base.css`, добавлен
  `font-display: swap`. Внешних запросов у страницы не осталось ни одного.
- **Удалена форма рассылки** в футере: она отправляла email на `getform.io`,
  которым владелец не пользуется. Вместе с ней убран её inline-скрипт и
  мёртвый код подписки на чужой Mailchimp-список, оставшийся от шаблона
  (`mailChimpURL`, `ssAjaxChimp`).

## Что нужно сделать вручную

1. **Google Search Console** — https://search.google.com/search-console:
   подтвердить домен, отправить `https://pandatv.online/sitemap.xml`,
   запросить индексацию главной.
2. **Bing Webmaster Tools** — https://www.bing.com/webmasters: то же самое.
   Bing питает Copilot и частично ChatGPT Search.
3. **Яндекс.Вебмастер** — если нужен трафик из СНГ.
4. **Проверить разметку** — https://search.google.com/test/rich-results
   и https://validator.schema.org/ (вставить URL главной).
5. **Проверить скорость** — https://pagespeed.web.dev/. Основной резерв:
   `hero-bg.jpg` весит много, а jQuery + плагины грузятся синхронно.
6. **`PandaTV/privacy.html` заполнена полностью** — незаполненных мест не
   осталось (`grep -c 'class="fill-me"' PandaTV/privacy.html` возвращает 0).
   Решения владельца, зафиксированные в тексте: оператор — Mykola Shevchenko
   (частное лицо, Украина), адрес указан по актуальному названию улицы
   (проспект Дмитра Яворницького, бывший Карла Маркса), представитель в ЕС
   по GDPR ст. 27 не назначается — сервис полагается на исключение ст. 27(2)
   для эпизодической обработки небольшого объёма данных.
   Перед публикацией текст стоит показать юристу — в частности, чтобы
   подтвердить применимость этого исключения.
7. **Кнопки «Get Started» в тарифах** ведут на `href="#0"` — JS перехватывает
   клик и открывает модалку, но для краулера это пустые ссылки. Лучше заменить
   на `href="#pricing"` или на прямую ссылку в Telegram.
8. **Если появятся новые страницы** — дописать их в `sitemap.xml`, `llms.txt`
   и `llms-full.txt` и обновить `lastmod`.

## Замечание о контенте

Сайт одностраничный и на одном языке (английский). Основной рост трафика даст
не техническая оптимизация, а новые страницы под конкретные запросы: инструкции
по настройке для разных устройств (Samsung Smart TV, Android TV, Enigma2),
список доступных стран и каналов, разбор «что такое TorrServe». Под каждую
такую страницу — свой `<title>`, `description` и запись в `sitemap.xml`.

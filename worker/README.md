# Релей заявок — установка за 5 минут

Воркер принимает заявку с формы на сайте и сам отправляет её в Telegram и на
почту. Токен бота при этом лежит на серверах Cloudflare и в браузер посетителя
никогда не попадает.

Нужен бесплатный аккаунт на https://dash.cloudflare.com/sign-up — домен туда
переносить **не надо**, воркер живёт на отдельном адресе вида
`pandatv-lead-relay.<ваш-логин>.workers.dev`.

## Шаг 0. Новый токен

Если старый токен ещё не отозван — сделайте это первым делом:
[@BotFather](https://t.me/BotFather) → `/mybots` → ваш бот → *API Token* →
**Revoke current token**. Новый токен скопируйте, но **никуда не вставляйте** —
он понадобится на шаге 3, где его нужно будет вставить один раз в терминал.

## Шаг 1. Установить wrangler

```sh
npm install -g wrangler
wrangler login
```

Откроется браузер с подтверждением доступа к аккаунту Cloudflare.

## Шаг 2. Задеплоить воркер

```sh
cd worker
wrangler deploy
```

В конце команда напечатает адрес вида
`https://pandatv-lead-relay.xxxxx.workers.dev` — **сохраните его**, он нужен
для шага 4. Этот адрес не секретный, его можно спокойно пересылать.

## Шаг 3. Положить токен в секреты

```sh
wrangler secret put TELEGRAM_BOT_TOKEN
wrangler secret put TELEGRAM_CHAT_ID
```

Каждая команда спросит значение — вставьте токен (и `7405005534` для chat id,
если чат не менялся) и нажмите Enter. Значения уходят прямо в Cloudflare:
в файлы проекта, в git и в историю терминала они не записываются. Посмотреть
их потом нельзя — только перезаписать той же командой.

Проверить, что оба секрета на месте:

```sh
wrangler secret list
```

## Шаг 4. Переключить сайт на воркер

В `PandaTV/js/main.js` найдите строку:

```js
const LEAD_ENDPOINT = "https://formspree.io/f/mgvyejbk";
```

и замените адрес на URL воркера из шага 2. Всё — форма снова шлёт заявки в
Telegram, и параллельно дублирует их на почту через Formspree (адрес почты
задан в `wrangler.toml`, чтобы поменять — правьте `FORMSPREE_ENDPOINT` и
повторите `wrangler deploy`).

## Проверка

Откройте сайт, нажмите «Get Started» на любом тарифе, заполните форму
тестовыми данными и отправьте. В чате бота должно появиться сообщение.

Если не появилось — посмотрите живой лог:

```sh
wrangler tail
```

и отправьте форму ещё раз. Типичные причины:

| В логе | Что значит |
|---|---|
| `Telegram API responded 401` | токен неверный или отозван — повторите шаг 3 |
| `Telegram API responded 400` | неверный `TELEGRAM_CHAT_ID`, либо вы ни разу не писали боту `/start` |
| `403 Forbidden` в ответе | запрос пришёл не с `https://pandatv.online` — проверьте `ALLOWED_ORIGIN` в `wrangler.toml` |
| ничего не появляется | сайт всё ещё шлёт на старый адрес — проверьте шаг 4 |

## Правило

Токен вводится **только** в `wrangler secret put`. Не вставляйте его в
`wrangler.toml`, в `main.js`, в переписку и в issue на GitHub — всё это
публично или становится публичным.
